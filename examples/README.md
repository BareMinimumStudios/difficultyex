# Configuration examples

Use the [current configuration reference](../docs/CONFIGURATION.md) for supported 1.21.1 JSON5 keys and examples. Merge fragments into `config/difficultyex/config.json5` while the server is stopped, then restart and run `/difficultyex validate`.

`default/rules.jsonc` is an old design sketch for a preset/rules engine. It is not loaded by the 1.21.1 port and must not be installed as a runtime configuration.
