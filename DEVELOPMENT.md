# Development

[Project](README.md) · [Documentation](docs/README.md) · [Publishing](docs/RELEASING.md)

Use Java 21 and the checked-in Gradle wrapper. Dependency versions are pinned in [libraries.toml](libraries.toml).

```powershell
.\gradlew.bat clean test build
```

On Linux or macOS, use `./gradlew clean test build`. In IntelliJ, import build.gradle.kts, select Java 21 and run the same tasks through Gradle.

Shared gameplay code uses Cloche's common API. Mixins and client Java in src/loaderShared/java compile against each loader's full game classes. Loader client/server run configurations are generated by the build.

JARs are written to build/libs and include both license notices. CI runs JVM and release-tool tests, verifies the manifest and uploads JARs and test reports.
